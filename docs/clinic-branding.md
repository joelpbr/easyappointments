# Identitat visual de la clínica

A **Configuració → General** es poden modificar:

- **Nom de l'empresa:** capçalera, títols de les pantalles, reserves i correus.
- **Logotip:** capçalera, accés, reserves, icones del navegador i imatge dels enllaços compartits.
- **Color de l'empresa:** capçaleres, navegació i elements principals.
- **Color d'accent:** botons i ressaltats. Els tons suaus i el contrast del text es calculen automàticament.

Després de desar, recarrega la pàgina per aplicar els canvis. Les altres pestanyes els adoptaran quan es recarreguin.
El logotip admet PNG, JPG, WebP i GIF de fins a 2 MB. En eliminar-lo es recupera la imatge predeterminada.

L'adreça, el telèfon, el correu i l'enllaç de la clínica també són ajustos generals.
Els colors assignats explícitament als tractaments o cites i els colors d'avís/error conserven el seu significat.
No cal cap migració de base de dades per afegir aquests ajustos.
